存储与安全边界:
  • MCP_REFRESH_TOKEN 持久化存储在 .mcp.json 中。
  • Access Token 仅驻留在 Proxy 内存中，过期前自动刷新。
  • TOKEN_KEY 仅存在于远端服务器，本地不解密。
为什么需要 Sidecar 模式?
  • 安全隔离: 模型无法修改 user_id 或伪造 Token。
  • 透明转发: 代理不解析业务 JSON-RPC，仅注入 Auth Header。
  • 灵活扩展: 新增 Tool 只需改远端服务，代理零修改。
  • 分层审计: 代理记录网络调用，远端记录解密与业务日志。
