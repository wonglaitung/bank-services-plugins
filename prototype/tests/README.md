# AI Agent 测试案例

本文档包含在 Claude Code 等 AI Agent 中输入的自然语言测试案例，用于验证财务接口功能。

## 测试案例列表

### 案例 1：查询可用指标

**用户输入**：
```
有哪些财务指标可以查询？
```

**预期响应**：AI 调用 `get_finance_dictionary` 工具，返回 8 个财务指标列表，包括净利润、不良贷款率、资产总额等，并说明每个指标的同义词和单位。

---

2025 年净利润为 125,000 万元（BR001 机构）

## 实际测试结果

以下是在 Claude Code 中执行的实际测试记录，包含完整的对话过程和分析输出。

### 实测案例 A：跨年净利润对比分析

**用户输入**：
```
查一下这三年的纯利润，并对比分析。
```

**工具调用过程**：
1. `get_finance_dictionary` — 查询"纯利润"对应的标准指标名
2. `query_financial_metrics` (metric="NET_PROFIT", granularity="yearly") — 获取三年数据

**AI 实际响应**：

最近三年净利润对比分析

| 年份 | 净利润（万元） | 同比增长 | 增长额（万元） |
|------|----------------|----------|----------------|
| 2023 | 98,000 | - | - |
| 2024 | 112,000 | +14.29% | +14,000 |
| 2025 | 125,000 | +11.61% | +13,000 |

**分析结论**：

1. 整体趋势：持续稳健增长
   - 三年净利润从 9.8 亿增长至 12.5 亿，累计增长 27.55%
   - 年均复合增长率 (CAGR) 约 12.9%，表现优异

2. 年度表现对比
   - 2024年：增长势头最强，同比 +14.29%，增加 1.4 亿元
   - 2025年：增速略有放缓至 +11.61%，但绝对增量仍达 1.3 亿元

3. 增长质量评估
   - 增速虽从 14.29% 回落至 11.61%，但仍保持两位数增长
   - 绝对增量稳定在 1.3-1.4 亿元区间，说明盈利能力扎实

4. 潜在关注点
   - 2025 年增速放缓约 2.7 个百分点，建议关注：
     - 净利息收入变化趋势
     - 不良贷款率是否上升
     - 业务规模（存贷款余额）增长情况

---

### 实测案例 B：多指标关联深度分析

**用户输入**：
```
进一步查询净利息收入、不良率等关联指标
```

**工具调用过程**：
1. `query_financial_metrics` (metric="NET_INTEREST_INCOME", granularity="yearly")
2. `query_financial_metrics` (metric="NPL_RATIO", granularity="yearly")
3. `query_financial_metrics` (metric="LOAN_BALANCE", granularity="yearly")
4. `query_financial_metrics` (metric="DEPOSIT_BALANCE", granularity="yearly")

**AI 实际响应**：

#### 核心指标汇总表

| 指标 | 2023年 | 2024年 | 2025年 | 三年变化 |
|------|--------|--------|--------|----------|
| 净利润（万元） | 98,000 | 112,000 | 125,000 | +27.55% |
| 净利息收入（万元） | 450,000 | 485,000 | 520,000 | +15.56% |
| 不良贷款率（%） | 1.85 | 1.72 | 1.58 | -0.27pp |
| 贷款余额（万元） | 5,200,000 | 5,800,000 | 6,400,000 | +23.08% |
| 存款余额（万元） | 6,800,000 | 7,500,000 | 8,200,000 | +20.59% |

#### 分项分析

**1. 净利息收入 — 盈利核心引擎**

| 年份 | 净利息收入 | 同比增长 | 对净利润贡献率 |
|------|------------|----------|----------------|
| 2023 | 45亿 | - | 21.78% |
| 2024 | 48.5亿 | +7.78% | 23.09% |
| 2025 | 52亿 | +7.22% | 24.04% |

分析：
- 净利息收入稳步增长，年均增速约 7.5%
- 净利润占净利息收入比例稳定在 23-24%，说明息差管理效率良好
- 2025年增速略放缓（7.22% vs 7.78%），与净利润增速放缓趋势一致

**2. 不良贷款率 — 资产质量持续改善**

| 年份 | 不良率 | 同比变化 | 风险评估 |
|------|--------|----------|----------|
| 2023 | 1.85% | - | 中等风险 |
| 2024 | 1.72% | -0.13pp | 改善 |
| 2025 | 1.58% | -0.14pp | 持续改善 |

分析：
- 不良率连续两年下降，累计下降 0.27 个百分点
- 资产质量明显改善，风险抵补能力增强
- 这解释了为何净利润增速放缓但盈利质量提升

**3. 业务规模 — 存贷款双增长**

| 年份 | 贷款余额 | 贷款增速 | 存款余额 | 存款增速 |
|------|----------|----------|----------|----------|
| 2023 | 520亿 | - | 680亿 | - |
| 2024 | 580亿 | +11.54% | 750亿 | +10.29% |
| 2025 | 640亿 | +10.34% | 820亿 | +9.33% |

分析：
- 贷款增速从 11.54% 回落至 10.34%，放缓 1.2pp
- 存款增速从 10.29% 回落至 9.33%，放缓 0.96pp
- 规模扩张放缓是净利润增速下降的主因之一

#### 综合诊断

**净利润增速放缓的原因**

| 因素 | 影响方向 | 说明 |
|------|----------|------|
| 净利息收入增速放缓 | ↓ 负面 | 7.78% → 7.22%，息差收窄压力 |
| 业务规模增速放缓 | ↓ 负面 | 贷款增速降 1.2pp，存款增速降 0.96pp |
| 不良率下降 | ↑ 正面 | 拨备计提减少，释放利润空间 |

**关键发现**

1. 息差压力显现：净利息收入增速低于贷款规模增速，说明净息差 (NIM) 在收窄
2. 风险管控优秀：不良率持续下降，资产质量改善对冲了部分息差压力
3. 规模驱动减弱：业务扩张速度放缓，需关注是否为主动调控还是市场需求变化

**建议关注方向**

1. 净息差走势：建议查询季度数据，观察息差收窄是否为行业性趋势
2. 拨备覆盖率：不良率下降的同时，拨备是否充足
3. 非息收入：是否有其他收入来源弥补息差压力
