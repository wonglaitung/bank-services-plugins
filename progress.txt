# 项目进展记录

## 当前状态

项目包含自定义 Skills 和 MCP 安全认证原型两大模块。

### 已完成

1. **excel-auto-fill Skill** (2026-04-11)
   - Excel 模版自动填充功能
   - 支持多种标记格式和匹配策略
   - 已归档

2. **anomaly-detector Skill** (2026-04-11)
   - 时间序列异常检测
   - 支持 Z-Score 和 Isolation Forest 方法
   - 新增 --lookback 参数（自动时间单位转换）
   - 修复 Isolation Forest lookback_days=0 bug
   - 重构 SKILL.md 文档结构

3. **跨平台路径规范化** (2026-04-12)
   - 为 anomaly-detector 和 excel-auto-fill 添加 `path_utils.py` 模块
   - 支持混合路径格式（Unix `~/` + Windows `\`）
   - 自动处理波浪号扩展和反斜杠转换
   - CLI 脚本集成路径规范化处理

4. **MCP 安全认证原型** (2026-05-25)
   - Sidecar 模式架构实现
   - Access Token + Refresh Token 双 Token 机制
   - Token 自动刷新和吊销支持
   - IDOR 防护（工具不接受 user_id 参数）
   - 管理员权限工具（list_all_users）

5. **MCP 工具描述最佳实践文档** (2026-05-26)
   - v1.1.0 版本
   - 包含术语规范、命名规范、工具模式库
   - 大宽表/数据仓库场景指南
   - 自动化验证脚本
