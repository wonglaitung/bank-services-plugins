# 同步原型设计到安全方案文档

将 MCP 原型已验证的设计同步到安全方案文档。

## 何时使用此技能

当以下情况发生时使用：

- 原型完成了新的功能验证
- 原型代码有重要修改
- 安全方案文档需要更新以反映原型验证结果

## 执行流程

**重要**：执行同步时必须按照以下顺序：

1. **第一步**：检查原型代码实现，更新 `docs/mcp_prototype_sidecar.md`
   - 读取原型代码文件，确认最新实现
   - 直接更新原型文档，确保代码示例与实际代码一致
   - 这是主文档，必须首先更新

2. **第二步**：对比原型文档和安全方案文档
   - 识别需要同步的内容
   - 生成同步报告

3. **第三步**：更新安全方案文档
   - 根据同步报告更新 `docs/mcp_security_authentication.md`
   - 确保方案文档反映原型验证的设计

4. **第四步**：更新 README
   - 更新 `prototype/README.md` 反映最新状态

5. **第五步**：确认提交和推送
   - 询问用户是否提交更改
   - 执行 git commit 和 git push

## 输出格式

同步报告包含：

1. **原型文档更新** - 更新的原型文档内容摘要
2. **已同步项** - 原型和方案一致的内容
3. **待同步项** - 原型有但方案缺少或过时的内容
4. **同步建议** - 具体的修改建议

## 注意事项

- **原型文档是主文档**：必须先更新原型文档，再同步到其他文档
- 同步前确保原型测试通过
- 大的架构变更需要用户确认后再执行
- 同步完成后需要询问用户是否提交和推送
